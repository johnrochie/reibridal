Homepage hero photos
====================

Any photo you put in this folder shows up in the rotating background
on the homepage. You control it — could be 1 photo, could be 50.

How to use it:

1. Drop JPG, PNG, WebP or AVIF files directly into this folder.
2. They play in filename order. To control the order, start each
   filename with a number: 01-front-door.jpg, 02-bride-veil.jpg, and
   so on. Without numbers they just sort alphabetically.
3. To take a photo out of the rotation, delete it from this folder
   (or move it somewhere else).
4. If this folder is empty, the homepage automatically falls back to
   showing photos from the dress catalogue instead — so it's never
   blank.
5. Photos should be reasonably web-sized (under ~5MB each works best)
   and roughly widescreen (this fills the full browser width).

This file itself does nothing — delete it if you like, or leave it
here, it won't show up on the site.
